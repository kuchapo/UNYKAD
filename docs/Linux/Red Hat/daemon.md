# **daemon**

Ein Daemon ist unter Linux eine dauerhaft im Hintergrund laufende Prozess‑Art, die auf Ereignisse, Anfragen oder Aktionen wartet und dann darauf reagiert.
Er wartet typischerweise auf Trigger wie Netzwerk‑Anfragen, Timer‑Ereignisse oder Hardware‑Events.
Bekannte Beispiele sind: sshd, cron, cupsd, systemd-journald.
Historisch haben nicht alle Daemons zwingend ein „d“ im Namen, und cron ist eines dieser Beispiele.
